1. 프로젝트 개요

무엇을 만들었나?

SK엔무브 마케터·영업전략 담당자를 위한 6개국 윤활유 시장 인텔리전스(MI) 뉴스레터를 자동으로 수집·분석·생성·발송하는 클라우드 SaaS 시스템.

기존 로컬 Python 스크립트 파이프라인을 맥북 없이도 클라우드에서 자동 실행되는 웹 서비스로 전환했습니다.
